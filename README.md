## 📖 Sobre o repositório

Este repositório reúne os **exercícios e desafios do Mundo 4** do curso **[Curso em Vídeo](https://www.cursoemvideo.com/)**, dedicado à **Programação Orientada a Objetos (POO)** em Python.

O objetivo é consolidar, na prática, os quatro pilares da POO:

<table align="center">
<tr>
<td align="center" width="200">
<img src="https://cdn-icons-png.flaticon.com/128/2620/2620465.png" width="60"><br>
<b>Encapsulamento</b><br>
Proteção de atributos e uso de métodos de acesso
</td>
<td align="center" width="200">
<img src="https://cdn-icons-png.flaticon.com/128/2913/2913461.png" width="60"><br>
<b>Herança</b><br>
Reaproveitamento de código entre classes
</td>
</tr>
<tr>
<td align="center" width="200">
<img src="https://cdn-icons-png.flaticon.com/128/1055/1055666.png" width="60"><br>
<b>Abstração</b><br>
Representação simplificada de entidades do mundo real
</td>
<td align="center" width="200">
<img src="https://cdn-icons-png.flaticon.com/128/1055/1055687.png" width="60"><br>
<b>Polimorfismo</b><br>
Múltiplos comportamentos para um mesmo método
</td>
</tr>
</table>

## 🗂️ Estrutura do projeto

```
poo/
├── 📁 desafios/            # Desafios propostos pelo curso
├── 📁 desafios proprios/   # Desafios extras criados por conta própria
├── 📁 exercicios/          # Exercícios de fixação de POO
├── 📁 rich/                # Experimentos com a biblioteca Rich (saída no terminal)
├── 📁 testes/              # Scripts de teste e validação
├── 📁 .vscode/             # Configurações do editor
└── 📄 .gitignore
```

---

## 💡 Conceitos praticados

- ✅ Classes e Objetos
- ✅ Atributos e Métodos
- ✅ Construtores (`__init__`)
- ✅ Encapsulamento (atributos privados/protegidos)
- ✅ Herança e sobrescrita de métodos
- ✅ Abstração de entidades do mundo real
- ✅ Polimorfismo
- ✅ Métodos especiais (`__str__`, `__repr__`, etc.)
